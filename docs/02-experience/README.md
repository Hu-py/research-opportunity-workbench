# Research Atlas · 前端 UX 与产品信息架构

**当前产品范围基线：V1.0（2026-11-22）**
**视觉基线：V0.5 黑白极简设计。**

本目录维护 Research Atlas 用户端的信息架构、页面规格、设计决策和历史原型。

## 当前正式架构

Research Atlas 普通用户端只保留两个一级入口：

- **对话**：私人对话、团队对话、GPT 调用、深度研究。
- **研究台**：团队周报、个人周报、定向科研任务、研究设置。

底层共用能力由场景自动调用，不独立设置菜单：
- 文献发现与证据整理
- 科研问题与方法分析
- 创新性、可行性与证据审查
- 团队与个人画像匹配
- 报告、引用、反馈与运行记录

Development Studio、A/B 实验、版本管理和研发审批属于独立研发管理，不进入普通用户导航。

## 版本关系与实施纪律

- V0.5 保留为历史视觉与交互原型，不覆盖历史文件。
- V1.0 是当前产品功能范围和导航结构的唯一基线。
- 当前静态 HTML/旧版 React 组件的存在不代表其所有功能都属于 V1.0。
- 前端重构需单独实施，并逐项验证真实后端、权限和持久化；不以静态演示作为验收。
- 新增功能必须说明它属于 SC01、SC02、SC03、研究设置还是独立研发管理；不能归入这些范围的功能默认不进入普通用户端。
