# PU-003：待人工审阅的八模块阅读笔记

以下是执行代理在模型输出完成后的原文复核笔记，**不是模型原始输出，也未回填到生成提示**。模型原文见 runs/PU-003 的 R0/R1/R2 JSON；两版 R2 校验失败，不可用本笔记替代其结果。页码按用户 PDF 的 1–11 页定位；证据仍未获独立人工认证。

1. **原有问题（source_supported）**：p2 §1.1–1.2 综述摊贩分布、影响因素、政府治理及正负外部性；作者认为高频观测困难，也较少比较不同主体对负外部性的感知。已有研究不是单纯“只会识别在哪里”，不能抹去其机制和治理研究。
2. **新问题（source_supported）**：p3 §1.3 明确问执法上报是否全面/无偏，12345 投诉呈现的图景有何不同，以及治理含义。真正的问题不等于“用 XGBoost 预测摊贩”。
3. **重新定义（analyst_inference）**：由把记录当成活动的观测，转向审视“谁在什么制度/生活条件下观察和记录”。p9 进一步将偏差视为部分研究目标，而不只是噪声。此概括不是已验证的创新类型，也不必强归 PU-001/002。
4. **观测差异（source_supported + 边界）**：p6 §3.1 和 Fig.4 显示执法上报更集中于工作时间和中心区域，投诉较分散、更多发生于休息时间；§3.2 又明确存在缓冲区交集。记录差异不能直接等同于真实行为差异，也不能将投诉当成不受选择影响的真值。
5. **方法必要性（analyst_inference，依据 p3–5）**：比较问题需要保留来源、时段、空间单位，而不是先混合两源。Tobit、SVM、XGBoost 是作者选用的实现；换成有效的计数/发生概率模型，观测主体与记录机制的问题仍成立。大量零值不自动证明 Tobit 的删失假设；预测变量重要性一致也不等于因果机制验证。模型输出主要复述选型，未充分给出这一反事实。
6. **知识增量（source_supported 的作者主张；新颖性 unverified）**：p8–9 把同一地区两种记录的时空与协变量结构作比较，并讨论为何偏差具有研究意义。p8 明确说部分集聚/商业联系与既有研究一致，不能把这些全部当新发现。没有独立全文查新，不能认证首次提出偏差或多主体视角。
7. **证据边界（source_supported / analyst_inference 分开）**：p9 作者承认缺乏“God's-View”而无法检验某些解释；p10 承认单案例数据限制。由此推断，巡逻强度、居民容忍度、治理三方共赢等不能视为本研究已识别的因果效果。p4 数据受协议/NDA 管理，不代表团队现已获得使用权。
8. **可迁移判断（analyst_inference）**：当多个记录渠道出现差异时，先建立记录生成链：真实事件→被观察→被认为值得记录→上报/投诉。若渠道具有不同选择机制，差异本身可成为问题，但必须有可比较单位、覆盖信息和区分解释的额外观测。失败反例：仅凭投诉少就推定负外部性低；或加入新算法但不改变解释目标。独立抽样观测、投诉渠道可及性调查属于待验证的后续思路，不是论文已经完成的实验。
