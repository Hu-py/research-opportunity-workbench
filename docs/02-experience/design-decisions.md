# Research Atlas · 前端设计决策记录

## UX-ADR-0001 · V0.5 页面结构基线

- **日期：** 2026-11-14
- **状态：** Accepted — design baseline
- **批准内容：** 用户明确确认采用 V0.5 并授权正式归档与推送 GitHub。
- **对象：** 前端信息架构、黑白视觉、页面使用模式；**不包括自动上线或数据库/认证功能交付**。

### 决定

1. 两个平级一级入口：**对话**与**研究台**，默认打开对话。
2. 左侧固定图标栏；相邻动态二级侧栏：对话模式显示会话树，研究台模式显示四个子模块。
3. 「研究专题、科研发现、知识资产、管理与设置」是**研究台二级模块**，不与对话平级。
4. 页面不展示 Slogan、架构总览或重复顶部功能导航。
5. 黑白灰极简研究机构风格；根据任务采用聊天、项目档案、研究时间轴、知识检索和配置面板等不同界面。
6. 研究画像支持经过审核的团队画像与私有个人画像，不自动混合两类信息。

### 被否决的方向

- 统一五个业务一级模块全部平铺在全局侧栏。
- 将架构总览或统计大屏作为登录默认主页。
- 顶部与左侧重复模块入口。
- 通过彩色仪表盘、Slogan 或装饰性 Hero 表达产品定位。
- 在设计原型中假装真实科研 Agent、权限控制与生产数据已经实现。

### 执行和修改纪律

- 本文件和 `milestones/v0.5/index.html` 是已批准的历史版本；后续设计必须建新里程碑（如 V0.6），不要覆盖 V0.5。
- 当前批准版的入口可随未来获批准版本更新；正式 Next.js 实施及部署使用独立 PR，必须保留旧模块功能并进行安全与回归验收。
- 如需推翻导航层级，新增 UX-ADR 或明确更新本记录并注明原因；不是仅仅修改 CSS。
