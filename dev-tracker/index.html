ACCEPTANCE RULES

如何让进度自动更新 / Workflow

01建立开发任务

在 GitHub 创建 Issue，明确功能目标、技术路径、验收条件和预期结果。

02提交代码并关联任务

PR 描述中使用 Closes #任务编号，合并后 GitHub 自动关闭对应 Issue。

03自动测试与可视化

GitHub Actions 给出最新测试状态。本页自动刷新 Issues、PR 和 commits。

04补充真实验收结果

在 Issue 中添加线上验证、结果链接及阻塞项；不要把 CI 通过等同于科研验证。

＋ 新任务 / 问题 ⌁ Pull Requests ✓ CI 检查记录
