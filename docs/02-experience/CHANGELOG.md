# Research Atlas 前端设计变更记录

## V0.5 — 2026-11-14 · Accepted design baseline

**视觉：** 黑白灰极简，弱化装饰与仪表盘感。

**导航：** 全球一级入口收敛为「对话／研究台」；二级侧栏按一级入口动态切换；彻底移除顶部重复模块导航。

**主页：** 对话默认入口；无 Slogan、Hero 和架构总览。

**研究台：** 四个二级模块分别以项目档案、科研发现、知识检索和配置控制台呈现。

**画像：** 团队正式画像／个人私有画像共存，权限语义分离。

**归档：** 首次锁定 HTML 里程碑，设置当前设计入口、规范和设计决策。

**范围说明：** V0.5 是 UX 设计版本，不代表 Research Atlas 产品版本，也不代表前端 Next.js 已重构/上线。

## V0.4 — 历史讨论版

讨论过「一个工作台，五种专业界面」以及五个业务平行导航方案。经后续评审，导航层级与登录默认页已经被 V0.5 取代；V0.4 并非正式实现基线。
