# R7.2｜直接领域文献证据恢复与论文级科学价值门槛

状态：R7.1 真实同源 A/B 失败后的首次联合修复；R6.4.5 / R7.1 原始报告不可修改。

## 真实失败证据（Shen et al. 2026 TRD）

- R7.1 A/B source SHA 相同，pipeline SHA=cbbf9908…；完整运行、匿名评价和解盲完成。
- gate-off：19 DeepSeek calls，3 篇符合来源/领域文献，议程 1 条但为指标效度与路径模型补验。
- gate-on：6 DeepSeek calls，模型宣称 independent_study 的路线 2 条，但实际可引用先例 0；**16 条检索候选全部被来源目录隔离**，未形成任何合格议程。
- 两组均 hard_failure，盲评计分 0；但独立问题层级 gate-on 优于 off（科学价值子项 2 vs 1 /5）。
- 科研问题和文献断裂，是可归因的基础能力问题。不能假称模型已经提炼可发表创新。

## R7.2 修复与设计

1. **OpenAlex Source-ID 精确解析**：运行时仅对已核准的 A/B/C/D 来源名字调用公开 OpenAlex `/sources`；只接受标准化后完全同名且无冲突的ID。与 Owner 已解析ID合并。缺失/网络失败/歧义全部写入审计，不静默添加期刊。
2. **冻结证据来源**：Source-ID 映射与解析状态同源论文事实一起冻结，gate-on 继承完全相同的ID/检索约束。新增 resolver 加入 pipeline SHA，旧 R7.1 检查点不得用新版本恢复。
3. **受控证据覆盖恢复**：初始查询缺少 A、B、D 之一时，各最多额外用 1 次短查询，查询仍限制在相应已核实的来源 ID 里，且所有候选继续经领域与摘要核验；不增加 DeepSeek 模型调用阶段。
4. **独立科研议程保护**：一条综合议程至少包含1条明确自报为独立研究的路线。只有robustness_fix或mechanism_substudy的集合被排除，不得把对原指标的验证或换算法包装为“下一篇论文”。注意模型自报的 independent_study 也不是学科创新认证。
5. **报告输出**：当综合议程被拒绝时说明拒绝原因，而非空白输出。

## 有界预算与验收

- 每个新论文基线最多约18次来源解析查询（A/B核心、C精选、D领域专门期刊）；问题驱动works检索最多7条，A/B/D覆盖恢复每类最多1条（非模型调用）。
- 源名完全一致 + API 返回明确OpenAlex ID才允许请求端期刊过滤，不能写入伪造ID。
- 先跑离线测试和全量CI，部署后做新版本实验预检与完整 A/B。保留旧报告。
- 对比维度：直接文献精度/覆盖、反例与最近先例、独立论文的中心机制、规划决策、可证伪性、数据可行性。**若独立论文不能被证实存在则输出零条，而不是提高评分**。
- 本轮的先验直接文献检查基准包括 doi:10.1016/j.tra.2024.104077, doi:10.1016/j.trd.2026.105304, doi:10.1016/j.tre.2025.104314, doi:10.1016/j.physa.2026.131730, doi:10.1016/j.tra.2023.103687, doi:10.1016/j.jtrangeo.2025.104420，作为人工对照，**不向模型捏造全文证据**。
