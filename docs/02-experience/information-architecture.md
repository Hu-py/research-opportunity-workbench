# Research Atlas V0.5 — 页面树与导航规则

**状态：已确认的设计规范；实际代码实施状态：待开发。**

## 1. 唯一的全局一级入口

```text
Research Atlas
├─ 对话（默认首页）
│  ├─ 新建会话
│  ├─ 私人会话与历史
│  ├─ 团队共同会话与历史
│  ├─ 对话内科研 Agent / 任务调用
│  └─ 可展开证据、任务轨迹、专题关联
└─ 研究台
   ├─ 研究专题
   │  ├─ 列表、搜索、创建与归档
   │  └─ 详情：概览 / 讨论 / 证据 / 任务 / 决策
   ├─ 科研发现
   │  ├─ A 规划应用、B 城市科学、C 计算方法
   │  ├─ L0 客观统计、L1 跨论文研究信号
   │  ├─ L2 重点论文、L3 可选研究机会
   │  └─ 周报（团队 / 个人 / 历史）
   ├─ 知识资产
   │  ├─ 论文索引、来源与证据
   │  ├─ 抽象知识、关系及知识图谱切换视图
   │  ├─ 研究画像：团队正式 / 个人私有
   │  └─ 团队成果、方法及数据元信息
   └─ 管理与设置
      ├─ 成员及权限
      ├─ 模型、密钥与预算
      ├─ 采集来源与定时配置
      └─ 系统运行与审计
```

## 2. 全局结构

- **一级图标栏**：固定在左侧，只包含「对话」和「研究台」；用户图标或账户入口属于工具操作而非第三个业务一级模块。
- **上下文二级侧栏**：在对话模式展示私人/团队会话树；在研究台展示四个业务模块。不得将研究台二级功能与对话并列到最左侧。
- **顶部栏**：位置说明、全局检索与必要操作；不放二次模块导航。
- **主内容区域**：由当前模块选择合适布局；无广告标语、无架构总览首页、无大面积 Hero。
- **响应式**：窄屏收起上下文侧栏，保留两个一级入口与当前页面内容，提供明确的展开方式。

## 3. 作用域与数据语义

- 私人会话与个人画像默认仅本人可访问；团队会话、团队画像按权限可共享。原型仅模拟该关系，不能替代 API 级授权。
- 团队研究画像是经过审核的科研能力与数据元信息；个人画像是成员兴趣和偏好，不能静默覆盖团队正式画像。
- 研究发现的 A/B/C 是新的三类研究来源；**不可将旧 Radar B 的含义直接等同于新版 B**。
- L0 统计与 L1–L3 研究判断分层展示；仅有文献元数据时不能暗示已经阅读全文或验证创新性。

## 4. 样式

纯白/微暖白背景、近黑正文、灰色说明、轻量边框与小圆角、空间留白、适度的信息密度。非关键状态不使用彩色标签。卡片、时间轴和关键词筛选可以借鉴研究机构档案式页面，但不复制第三方品牌资产。
