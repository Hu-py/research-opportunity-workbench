## 三、科研判断

1. 同领域研究在当前有摘要的少数已标注论文中被全部保留，但多数真正直接近邻（9篇中6篇）没取得 OpenAlex 摘要，因此 **无法声称真实近邻召回率全面合格**。
2. R6.7 的核心短板仍是方法迁移通道：只有4/9暂定方法被保存为候选，部分有潜在价值的方法仍被隔离；一个跨域方法候选混入同领域池。
3. **不能声称 R6.7 比 R6.6 进步了28个百分点**。两轮测试集合、来源类别、算法实现和样本完整性不同，无法据此开展因果对比。
4. 使用同一套初评标签反复改阈值后再在这32篇上取得高分，只说明开发集适配，**不说明泛化**。
5. 模型提出具有完整输入输出映射及摘要支持的跨域方法，也不代表可执行性，更不能证明研究问题创新性；科学评价必须基于新论文、新独立评审与必要的最小实验。
