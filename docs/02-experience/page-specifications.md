## 交互规则

1. 登录后进入 **CHAT-01**，不经过架构总览或欢迎营销页。
2. 最左侧固定两个一级入口；二级侧栏内容随切换而变，并高亮当前选中对象。
3. 用户从任一研究台对象选择「讨论」可回到对话，带上获授权对象的 ID；不能暗中复制整份私人内容。
4. 对话选择「保存到专题」是显式操作；私人会话不因与团队对象关联就被自动公开。
5. 证据详情保留来源、处理级别和不确定性；研究机会的采纳与审核属于不同权限动作。
6. 研究台各业务模块具有不同布局，不采用统一仪表板模版。
7. 所有可点击的原型控制都应说明是演示行为，不能假装已真实修改系统设置。
8. 搜索、键盘焦点、空状态、错误及无权限状态应在真实 Next.js 实施时补齐。

## 实现阶段必须验收

- 真正独立持久的私人/团队会话与 API 权限隔离。
- 刷新后对话和工作状态恢复，重复请求不产生重复消息。
- 研究专题对象的稳定 ID 与跨页面链接。
- 个人画像、团队画像和报告共享的访问控制。
- Agent 运行中的真实任务状态、失败与证据定位。
- 旧版 Research Atlas 功能迁移时不遗失数据和权限。

本版本的 HTML 仅为视觉、布局和演示交互基线；不能用作以上后端验收的证明。
