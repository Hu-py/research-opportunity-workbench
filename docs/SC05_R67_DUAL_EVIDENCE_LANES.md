## 1. 问题定义与证据链

R6.4.5 的真实 DeepSeek 双臂实验已完成且保留原评分。R6.6-A 在新论文主题上运行了15条 DOI 的公开 OpenAlex 检索（14条取得摘要），发现：
- 已解析同领域召回4/4，但领域精确率4/7；
- 4篇暂定无关学科均被隔离；
- 5篇暂定跨领域方法中只有2篇隔离，另3篇可能被当成同领域候选；
- 这些都是**单一评审者的暂定银标准**，不能据此宣称新颖性或给R6.7调参后的真实准确率。

R6.7 必须把“研究对象/问题的近邻”与“分析方法的跨领域启发”区分为不同来源、不同证据强度和不同审批状态。不得把二者混为一类，也不得因丢弃跨域论文就声称扫描质量好。

## 2. 双通道结构

**A / 同领域近邻（domain-neighbor lane）**

retrieved papers → 现有领域与摘要筛选 → 论文-诊断关联审核 → 
同领域、相关性 close、摘要逐字核验且 direct/counterexample 关系可解释时，才作为 provisional nearest candidate。此过程依然不证明科学新颖性、历史优先性或全文可比性。

**B / 跨领域方法（method-transfer lane）**

检索候选中未通过领域匹配者 → 必须有真实摘要和明确、非泛化的算法/统计方法名称 → 候选队列，状态 unreviewed_method_candidate。查询阶段依据原有 need 字段区分：need=method 的搜索不追加源学科锚点，其余 theory/counterexample/validation 继续添加源领域锚点。最多7条检索请求，不增加 OpenAlex 请求数量。检索结果的领域与证据资格仍独立判断，不因检索意图自动认定可迁移。

现有 research_redesign 模型调用可**选择性**提出方法迁移提案，但需要具体 route_id 与原 DOI/paper_id、源输入、目标输入、源输出、目标输出、关键不变性假设、最小对比实验、否证与终止条件，并逐字引用来源摘要作为最低证据。这些字段由确定性验证器检查：
- 不存在的论文/路线 ID、空洞映射、假摘要都被拒绝并计入审计；
- 结构完整与引文准确的提案也仍是 needs_human_review；
- 没有人为审核时 human_approved 永远为0，不能写进 closest_paper_ids；
- 不创建第三方论文全文储存，不引入额外 DeepSeek 调用阶段；未来正式运行增加的提示词长度可能影响 Token 使用，需单独授权后衡量。

### 不等价边界

域内题目匹配不是直接机制证明；有方法术语不等于可迁移；摘要原文核验不等于研究方法确实能够迁移；结构检查通过不等于人工审核通过。

## 3. 不泄漏的开发验证

- DEV 使用 benchmarks/sc05_r67_synthetic_dev_v01.json，8条明确**虚构/合成**的单元用例，不能被呈现为真实期刊论文。
- 严禁用 R6.6 的15条 DOI 或当轮实际筛选结果训练、调阈值后再冒称其为全新留出集；那份银标准已暴露。
- 合成 DEV 测试重点：两个通道不互相借用证据、自引/无摘要处理、具体方法术语门槛、跨域输入输出与否证的格式、摘要原文核验、拒绝伪造论文编号。
- 测试成功仅说明**工程约束在给定合成案例上成立**。仍需不同来源的独立人工双评真实开发集与新留出集才能评价学术效果。
