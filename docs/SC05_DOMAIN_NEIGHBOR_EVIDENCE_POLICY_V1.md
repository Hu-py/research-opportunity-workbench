# SC05 · 领域近邻文献检索与证据准入 V1 (R6.5)

更新：2026-11-18 · 适用：Research Atlas 单篇已发表论文 → 下一篇科研机会发现。**只保存论文元数据/摘要/溯源信息，不保存外部论文全文。**

## 1. 起因与目标

R6.4.5 的匿名 A/B 已真实完成：科学门控 70/100，基线 38/100。
然而，基线把哲学、语言学、企业管理、心理学等论文当作
轨道交通韧性“最近先例”。抽到了原样摘要，不等于该论文与目标
研究存在方法或机制上的可比性；跨领域概念类比尤其不能证明近邻。

本次 R6.5 是**检索证据链修复**，不是另一轮 DeepSeek 付费 A/B。
绝不修改 R6.4.5 原始评分、输出、哈希或检查点。

## 2. 双层筛选

1. **原文语境与检索排序。** 从论文的前八页提取有限领域词，按
   versioned domain ontology 粗识别研究对象；给过于笼统的模型查询
   附加相关领域提示（保留原始查询和实际执行查询）。只对 SC05
   启用 OpenAlex `relevance_score:desc` 与 `has_abstract:true`；
   团队周报继续沿用日期排序。最多七条查询、每条最多七篇，
   原流程最多取三十五篇，保留上限，不增加外部请求次数。
2. **论文领域与证据资格。** 对标题与可追溯摘要进行明确的同领域信号
   判断；自引、没有摘要、明显跨领域论文进入 quarantine 审计，
   **不得**进入“最近先例”的默认引用池。领域无法识别时保留
   线索，但禁止通过近邻准入，不将无结果解释为领域空白。

## 3. 直接近邻准入

LLM 提议的 `closest_paper_ids` 不是证据。只有同时满足以下条件，
才能暂时保留为“同领域相关候选”（仍不等于确认近邻/先例）：

- 文献通过领域检索筛选，并有可核验摘要；
- 模型给出 `relevance=close`；
- 对某条原论文诊断存在明确 `direct` 或 `counterexample` 关系，
  含具体关联解释，不接受没有中间机制的跨域 `indirect`；
- 摘要引文已与 OpenAlex 摘要逐字或空白归一化核验；
- 不能是同一篇源论文。

不满足资格的引用**从结构化最近候选字段撤销**，逐项审计原引用
ID、路线及撤销理由；不删除历史原始候选或伪造替代文献。报告显示
“模型声称的区别（没有可信直接近邻支撑）”，不是自动宣告原创。

**重要限制：** 这些只是最低的自动化必要条件，不代表已核对论文全文、
出处、实质研究重叠、发表时点、指标可比性或发表新颖性。
新发布论文可能只是“相关工作”，不能倒称原论文的“已有先例”。
`novelty_certified` 持续为 false。

## 4. 跨期刊与跨领域方法迁移如何保留

Research Atlas 的长期目标仍是跨领域方法迁移，但应采用两个清晰分离的通道：

- `domain_match`：与原文研究对象相近的工作，供近邻论证和竞争机制审查；
- `method_transfer_candidate`（后续人工审核通道）：
  不同学科的算法或框架可作为**方法启发**，但必须提出可操作的
  输入/输出映射、机制桥接、假设边界与检验方案，禁止直接称为同领域先例。

V1 先将跨域命中记录到 `search_relevance_audit.quarantined_records`，
不进入自动路线近邻池；不据此认定跨域技术无价值。未来可在审批后
迁移到独立方法图谱，本轮不自动新建标签或相信概念修辞类比。

## 5. 运行审计与验收

新增/扩展字段：

- `source_domain_profile`：识别出的领域、依据词和领域词表版本；
- `search_relevance_audit`：检索量、保留量、隔离量及逐篇原因；
- `prior_reference_audit`：可准入论文 ID、撤销最近候选数量、逐路线原因；
- `quality`：领域筛选、无可用近邻、被撤销的关系引用警告；
- `search_query` 保留原查询，`retrieval_query` 记录实际执行查询。

验收顺序：

1. 离线测试：交通韧性必须排除语言学/哲学，保留真的交通与网络客流论文；
   水文、儿童健康和未知领域均不会被硬编码成交通。
2. OpenAlex API 请求测试：SC05 显式切换相关性排序，其它扫描仍按日期；
   全程不使用真实密钥、无外部网络、无 DeepSeek 请求。
3. CI 通过后合并部署隔离 Render，核对 commit SHA、API 健康状态和
   Owner MCP 状态。
4. 使用**新的、未参与修复的论文**做后续科研质量评估；
   只有用户另行确认付费与实验范围时才开始新的真实双臂 DeepSeek。

## 6. 仍未解决的风险

领域词表是保守的可审计启发式：可能误排新颖的跨领域方法，也可能留下
含领域词但实质无关的论文。OpenAlex 排序按文本匹配与引用量等计算，
也不是科学可比性判断。领域识别失败、检索没有命中，或没有通过近邻筛选，
都不代表不存在先例。后续要加入可追溯方法图谱、人工黄金集、
领域内 hard negatives、发表时间先后校验和多篇论文盲评。

研究质量的改进证据必须来自预先登记的盲评与独立论文复验；
不能把“筛掉更多论文”“摘要通过率高”直接当作创新价值提升。
